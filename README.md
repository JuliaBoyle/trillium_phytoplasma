# The ecological dynamics and consequences of phytoplasma in a spring ephemeral

## Description of the data and file structure

This repository contains the field data collected from Koffler Scientific Reserve, summaries of spatial models resulting from iNaturalist data, and the files containing R code for analysis.

trillium_code.rmd should have all the code required for analysis. Other rmd files have relevant code that we've used along the way but may be outdated.

Data can be downloaded from the data folders. All data and code is also available on Dryad at DOI: 10.5061/dryad.fqz612k5d

## Files and variables

### R coding files

File: trillium_code.Rmd

Description: An R markdown file containing all analysis for the project. Can be opened in R and R studio statistical software.

File: ggField_sd.R 

Description: Adapted R code to create INLA spatial field standard deviations. Adapted from the ggregplot_0.1.0 package and specifically the ggField function which uses the posterior means of INLA spatial field random effects. Can be opened in R and R studio statistical software.

### Data from the field

File: Trillium and leafhopper sequencing results.xlsx

Description: Sanger sequencing results for forward and reverse amplified barcodes from plant and insect samples. Plants were amplified for phytoplasma 16S region, and insects for COI region. 

Variables:

Sample: Sample name. Phyto pos leaf samples are leaf samples from symptomatic trillium. Samples with COI indicate an insect sample, LH# signifies which leaf hopper morphotype is being tested. F and R at the end of the name indicate Forward or Reverse read respectively. 

File name: The name of the actual file received from sequencing center. 

Sequence: The nucleotide sequence received from the sequencing center.

Blast n megablast first result: When we inputted the nucleotide sequence into NCBI's Blast program using megablast algorithm on 18/07/2025, this was the taxonomic match with the highest percent matching identity.

Percent identity: The amount our sequence matched the best match in the database.

Relevant matches: The NCBI unique code for the samples with the highest matches.

Notes: Relevant notes, such as date of search or when the sequencing failed.

File: 2024 Trillium seed counts and predicted counts.csv

Description: Data on trillium measured for seed production and the modeled/predicted seed counts. NAs indicate the value was not measured or not relevant.

Variables:

ID: Unique ID for trillium individual

Infection status: Whether the trillium individual had any symptoms of phytoplasma presence. Marked as symptomatic or non-symptomatic.

lf length: Leaf length in cm

lf width: Leaf width in cm

stem diameter mm: Stem diameter in mm

fruit width: Fruit width in mm

fruit length: Fruit length in mm

transect number: number to indicate the transect the trillium was measured in

field notes: Notes on trillium status. Munched= evidence of herbivory. Antho=red pigment in the leaves presumed to be anthocyanins

Paired data plants: Whether the trillium individual was measured as part of a pair group (value=Yes) or measured for generating the link between trillium size and seed production (value=No).

seed count: The measured or predicted seed count of that trillium individual

seed count notes: Notes about seed count, usually to note why a count is 0 (e.g., seed pod deflated or no fruit produced).

seed count real or predicted: Whether the value in the seed count column was generated by counting the seeds that individual produced (value=Real), or whether it was generated by extrapolating the predicted seed count from the size of the trillium (value=Predicted).

pair number: The pair number linking the symptomatic and asymptomatic trillium. These paired trillium are close in space to one another. Trillium measured for seed count directly are not paired with other trillium.

Trillium Field Data - Leaf and Height Phenotypes.csv

Description: Data from 2023 measuring the phenotypes of symptomatic and asymptomatic trillium individuals.

Variables:

Plot: The 1 by 1 m plot where the trillium was measured in. This corresponds with the plots in the infection frequency datasets.

Population: General location in Koffler Scientific Reserve where the plots were located. Populations were designated by landscape features such as differing hill slopes.

Infection: Whether the trillium individual was symptomatic with phytoplasma or not. 0=asymptomatic, 1=symptomatic.

Stem diameter: Stem diameter in mm. NA indicates this value was not measured.

Leaf length cm: Leaf length in cm

Sepal length cm: Sepal length in cm

Height cm: Height in cm of the trillium from the ground to its longest petal.

Surveyor: Who measured the plant. JB=Julia Boyle. JY= Julia Yang.

Sepal to leaf ratio: The ratio of the sepal length to the leaf length.

Trillium Field Data - Multiyear.csv

Description: The full infection frequency and trillium density datasets including both 2018 and 2023 years.

Variables:

Plot: The label of the 1 by 1 m plot sampled. Plots were chosen haphazardly by throwing a flag into trillium.

Year: Whether the plots were sampled in 2023 or 2018.

Forest side: Whether the plot was sampled in the forest to the east or west of Dufferin Rd at the Koffler Scientific Reserve.

Population: General location in Koffler Scientific Reserve where the plots were located. Populations were designated by landscape features such as differing hill slopes.

Surveyor: Who sampled the plot. JB=Julia Boyle. JY= Julia Yang, AC= Amalia Caballero.

Latitude: Decimal latitude of the plot surveyed. When not recorded, this value is NA.

Longitude: Decimal longitude of the plot surveyed. When not recorded, this value is NA.

Young hemiptera: The number of non-flowering trillium with any evidence of hemiptera or sap sucking insects on the plant. Value is NA in 2018 because non-flowering trillium were not measured.

Young nohemiptera: The number of non-flowering trillium with NO evidence of hemiptera or sap sucking insects on the plant. Value is NA in 2018 because non-flowering trillium were not measured.

Health hemiptera: The number of asymptomatic (no phytoplasma) flowering trillium with any evidence of hemiptera or sap sucking insects on the plant. Value is NA in 2018 because these categories were not distinguished.

Health nohemiptera: The number of asymptomatic (no phytoplasma) flowering trillium with NO evidence of hemiptera or sap sucking insects on the plant. Value is NA in 2018 because these categories were not distinguished.

Infec hemiptera: The number of symptomatic ( phytoplasma) flowering trillium with any evidence of hemiptera or sap sucking insects on the plant. Value is NA in 2018 because these categories were not distinguished.

Infec nohemiptera: The number of symptomatic ( phytoplasma) flowering trillium with NO evidence of hemiptera or sap sucking insects on the plant. Value is NA in 2018 because these categories were not distinguished.

Total trilliums: The sum of flowering and non-flowering trillium individuals in the plot.

Total adult trillium: The sum of flowering trillium individuals in the plot.

Total infec trilliums: The sum of flowering symptomatic (phytoplasma) trillium individuals in the plot.

Freq hemiptera total: The number of non-flowering and flowering trillium both with evidence of hemiptera divided by the 'Total trilliums' column. Value is NA in 2018 because these categories were not distinguished.

Freq_infection_of_total: The 'Total infec trilliums' column divided by the 'Total trilliums' column. Value is NA in 2018 because non-flowering trillium were not measured.

Young_to_repro_ratio: The ratio of non-flowering trillium number to flowering trillium number in the plot. Value is NA in 2018 because non-flowering trillium were not measured.

Freq_infection_of_adults: The 'Total infec trilliums' column divided by the 'Total adult trillium' column. Because infection was only assessed in flowering trillium, this is a more accurate assessment of infection rate in the plot.

Freq_hemiptera_adults: The number of flowering trillium with evidence of hemiptera divided by the 'Total adult trillium' column. Value is NA in 2018 because these categories were not distinguished.

trillium_seed pairs.csv

Description: A file linking trillium identity to a trillium pair. These trillium and their pairs are used for the seed data.

Variables:

ID: Trillium individual identification. D means diseased, H means Healthy. 

pair number: The pair number linking the healthy and diseased trillium pairs. Diseased trillium were chosen as the focal individual and the nearest asymptomatic trillium was chosen from there to make the pair.

Trillium data collection - 2024 demography.csv

Description: Trillium demographic data measured in 2024. In 2024, we sampled 0.5 x 0.5 m plots centered around the focal asymptomatic and symptomatic individuals measured for seed production, and recorded the number of one-leaved, three-leaved vegetative, and three-leaved flowering trillium.

Variables:

ID: Trillium individual identification. D means diseased, H means Healthy. 

DH_type: Symptom status of the trillium. H=Healthy/asymptomatic, D=Diseased/symptomatic.

Date: the day and month the plot was assessed in 2024.

infected adult: Number of symptomatic (phytoplasma) flowering trillium in the plot.

adult count: Number of asymptomatic (no phytoplasma) flowering  trillium in the plot

juvenile count: Number of  trillium with 3 leaves but not flowering or budding in the plot

one leaf count: Number of  trillium with only 1 leaf in the plot

cot count: Number of cotyledon trillium in the plot

### Data from iNaturalist

iNat_alltrilliums 2025 03 14 539340.csv
The file containing data downloaded from iNaturalist. Data from iNaturalist can also be downloaded directly from https://www.inaturalist.org/observations. Data on white trillium (Trillium grandiflorum) should be downloaded for dates observed between 1965 and March 14th 2025, including only "research-grade" observations, and including all metadata and observation fields (including “Phytoplasma Infection?=Yes”). At March 14th, 2025, this dataset included 43,037 observations between 1967-2024 with 846 infected individuals. 

iNat observation list.xlsx

Description: A list of all observers, unique observation ID, and their linked observations.

Variables:

user id: A unique number representing the iNaturalist user

user login: The publicly available user login name of the observer

user name: The publicly available username of the observer

observation id: The unique observation id assigned to an iNaturalist observation

url: The link to the specific observation online at inaturalist.org

IM3.r_(1).rds

Description: An R object of the spatial model used to analyze the iNaturalist data. It can be opened in R. It contains summaries of the fixed and random effects. It is very computationally intensive to create from scratch in the code.
